# go_calculator
A simple calculator programmed using GO
Calculator GO 1.0

This is my first Go project, built while I started learning the fundamentals of the language.
The program demonstrates the use of switch cases, user input handling, and basic arithmetic operations.

1) Features
The calculator supports four operations:
Addition
Subtraction
Multiplication
Division (with zero-division handling)

2)How to Use
Copy or download the calculator.go file.
Create a new file named calculator.go in your editor.
Paste the code inside it.
Run the program using:
go run calculator.go
The terminal will prompt you to enter:
The operation (Add, Subtract, Multiply, Divide)
The first value
The second value
After that, it outputs the result instantly.
